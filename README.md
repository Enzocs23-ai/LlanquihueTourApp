## 📘 Descripción general del sistema
Este proyecto corresponde a la **Actividad Sumativa 1 (Experiencia 1: Descubriendo la lógica de clases en Java)** de la asignatura *Desarrollo Orientado a Objetos I*. Se trata de un sistema orientado a objetos desarrollado en Java para la agencia **Llanquihue Tour**, cuyo objetivo es modelar y registrar de forma estructurada a sus contactos y personal colaborador, aplicando principios de encapsulamiento, composición de clases, herencia y documentación técnica estandarizada.

El proyecto aborda la problemática de gestión manual y dispersión de información del caso planteado, estableciendo una arquitectura modular, extensible y orientada a buenas prácticas.

---

### 🧱 Estructura general del proyecto
```text
📁 src/
├── app/
│   └── Main.java   # Clase principal con el método main (pruebas y despliegue)
└── model/
    ├── Direccion.java    # Entidad de ubicación (utilizada para relación de composición)
    ├── Persona.java      # Clase base general del dominio
    └── Empleado.java     # Subclase especializada que extiende de Persona (herencia)
```

### ⚙️ Instrucciones para clonar y ejecutar el proyecto

1. Clona el repositorio desde GitHub abriendo tu terminal y ejecutando:
git clone https://github.com/Enzocs23-ai/LlanquihueTourApp.git

2. Abre el proyecto en IntelliJ IDEA.

3. Verifica que el SDK del proyecto esté configurado con Java 17 o superior.

4. Localiza el archivo Main.java dentro del paquete app y ejecútalo.

5. Revisa la salida generada por consola con los datos formateados por toString().
